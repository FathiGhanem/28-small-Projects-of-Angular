# 📦 Angular 28-Days Challenge Collection

Welcome to my intensive Angular learning journey! This repository is a curated collection of **28 mini-applications** built with Angular. Each directory represents a specific day of learning, covering everything from core directives to advanced API integrations and game logic.

---

## 🚀 Skills Showcased

- **Framework:** Angular 16+ (Components, Services, Directives, Pipes).
- **State Management:** Reactive programming with **RxJS**.
- **Styling:** Advanced **SCSS** (Flexbox, Grid, Animations).
- **Data:** Handling **REST APIs**, JSON data, and Local Storage.

## 🛠️ Installation & Usage

1. **Clone the repo:**

   ```bash
   git clone [https://github.com/FathiGhanem/28-small-Projects-of-Angular.git](https://github.com/FathiGhanem/28-small-Projects-of-Angular.git)
   ```

2. **Choose a project:**
   `cd day-x-project-name`

3. **Run it**
   `npm install && ng serve`
